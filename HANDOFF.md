# Промт для продолжения в другом чате или другой ИИ

Как использовать: откройте новый чат (Claude или другой ИИ), приложите файлы `index.html`, `schema.sql` (в нём уже есть всё из `migration_profile.sql`), `migration_series.sql` и этот `HANDOFF.md`, вставьте текст ниже. Если нужны только рекомендации фильмов, на сайте во вкладке «Профиль» есть кнопка «Скопировать промт для подбора фильмов»: она сама добавит ваши оценки.

Последнее обновление этого файла: 25.11.2026 (добавлены вкладки «Рекомендации» и «Друзья», нужен migration_friends.sql; ранее: вкладка «Главная»; стиль «Кинозал»; в коде есть сериалы и импорт CSV; проект передан второму пользователю, он работает в той же базе Supabase, что и автор).

ПРОЕКТ
Личный сайт-трекер фильмов (название «Поиск кадров») (аналог списка просмотренного на Кинопоиске, который у меня заблокирован). Для меня и пары друзей. Я живу в Украине, пишу по-русски, отвечай по-русски. Я «вайбкодер»: код сам не пишу, но с хостингом работал. Объясняй шаги простыми словами и давай готовый код целиком или точные замены с указанием места. Пользуюсь сайтом в основном с компьютера, но мобильная версия не должна ломаться.

СТЕК
- Один файл index.html (HTML, CSS, JS без сборки), хостинг GitHub Pages (открывается и в Украине, и в России).
- Supabase (бесплатный тариф): вход по e-mail и паролю, таблица movies, у каждого пользователя свой список (Row Level Security, схема в schema.sql; для сериалов нужна ещё migration_series.sql). Библиотека supabase-js подключена с cdn.jsdelivr.net. Используется publishable-ключ.
- TMDB API (ключ v3) для поиска фильмов, постеров, жанров, длительности и рейтинга. TMDB может не открываться без VPN.
- Шрифт Manrope с Google Fonts (если не загрузится, сайт использует системные).
- Ключи лежат в index.html в начале скрипта (SUPABASE_URL, SUPABASE_KEY, TMDB_KEY). Я вставлю их сам. Никогда не проси меня присылать secret-ключи.
